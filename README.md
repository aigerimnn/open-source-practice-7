# Open Source Practice 7

## Project Description
This repository was created to practice
open-source contribution workflow using GitHub.

## Repository Purpose
The main purpose is to learn how to work
with GitHub repositories, issues, and pull requests.

## Learning Objectives
- Create and manage GitHub repositories.
- Report issues and suggest improvements.
- Edit project documentation.
- Create branches and pull requests.
- Merge changes into the main branch.

## Technologies Used
- Git
- GitHub
- Markdown
